Qué problema resuelve

Una prueba automatizada debe ser fácil de reproducir, dejar evidencia legible y distinguir fallos reales de errores de configuración. El ejemplo muestra cómo separar cliente HTTP, casos API, navegación Selenium, Page Objects y captura de resultados.

Cómo verificarlo

  1. Abrir el repositorio público y consultar las instrucciones para Windows.
  2. Usar Python 3.12, pytest 8.3.4, Selenium 4.28.1 y Chrome/ChromeDriver locales compatibles.
  3. Ejecutar primero las pruebas API, después los cuatro tests completos.
  4. Revisar que los casos no se omitan silenciosamente y conservar la salida JUnit.

La verificación técnica publicada incluye los resultados locales del conversor y la distinción expresa entre tests del conversor y pruebas API/Selenium originales.
